# BG Jobs - Automated Sarkari Job Portal

Official repository for BG Jobs automated static portal deployed on GitHub Pages.

## Core Setup
- **Framework**: Static HTML/CSS + Python Generator
- **Deployment**: GitHub Actions (`.github/workflows/deploy.yml`)
- **Data Store**: `data/jobs.json`
- **Site URL**: `https://bgsarkariresult.github.io/bgjob/`
